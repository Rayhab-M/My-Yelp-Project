# Welcome to My Yelp
***

## Task
This project is a restaurant management web application built with ReactJS and AWS Amplify for authentication. The application allows users to sign up, sign in, and sign out while managing their own list of restaurants.

Challenges:
1.Implementing AWS Amplify Authentication (Sign-up, Sign-in, Sign-out).
2.Enabling users to add restaurants.
3.Displaying a list of restaurants separately.
4.Allowing users to view restaurant details by clicking on them.

## Description
To solve these challenges, the application is structured as follows:

1.Authentication System powered by AWS Amplify (Sign-up, Sign-in, Sign-out).

Restaurant Management allows users to:
* Add new restaurants with a name 
* View a list of user-created restaurants.
* Click on a restaurant to see its details.
* See a list of restaurants next to the sign-out button.

Component-Based Structure:

* App.js handles authentication and main layout.
* RestaurantList.js manages user-created restaurants.
* React Router ensures smooth navigation.


## Installation
npm install to install missing dependencies

Configure AWS Amplify:
amplify configure
amplify init

npm start to Run the Application.

## Usage
Authentication:
Sign up with an email and password.
Verify your email with the confirmation code.
Sign in to access the dashboard.

Adding Restaurants:
Enter a restaurant name in the input fields.
Click "Add" to add it to the list.

Viewing Restaurants:
Click on any restaurant in the list to see its details.
A list of restaurants is available in the sidebar.

Signing Out:
Click the "Sign Out" button to log out.
